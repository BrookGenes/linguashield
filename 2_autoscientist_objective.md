# Paste this into Adaption -> AutoScientist (objective / task description)

Given a short text message in any of English, Spanish, Swahili, Tagalog, Yoruba or Zulu, reply with ONLY a JSON object:
{"label": "scam" or "legitimate", "reason": "one short English sentence"}

Goal: catch as many scams as possible in every language, including lower-resource ones, while keeping false alarms on legitimate messages (bank notices, verification codes, delivery updates, family messages) low.

Use the dataset generated by Invent a Dataset for training. Do NOT use any other data.
