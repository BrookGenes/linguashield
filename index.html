How we used Adaption

  1. Red team

    We wrote a held-out test set in four languages and showed the keyword filter misses most non-English scams.

  2. Adaptive Data

    Invent a Dataset generated 4,000 synthetic scam and legitimate messages across English, Spanish, Swahili, Tagalog, Yoruba and Zulu, with hard negatives.

  3. AutoScientist

    It picked a Qwen3.5 4B model with LoRA fine-tuning and chose the training recipe on its own.

  4. Evaluate

    Adaption’s evaluation compared the adapted model with the base model head to head.

What changed

On Adaption’s head-to-head evaluation of our dataset, the trained model beat the base model.

Built for defense

  • All data is synthetic. Brands are placeholders like ExampleBank, links are written as [link], and no real victims or numbers appear.
  • The tool classifies messages. It does not write them.

What we’d be honest about

  • We did not run the trained model on our own test set. The 68% vs. 32% figure comes from Adaption’s evaluation.
  • The translate step also translated label values (“scam” became “estafa”), and some language tags were wrong. Our code reads those labels correctly.
  • The dataset has more scams than legitimate messages, which can raise false alarms.
